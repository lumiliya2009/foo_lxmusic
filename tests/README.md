
脚本使用实际的 `input_lxmusic.cpp` 和 `media_stream.cpp`，仅替换 foobar2000 主线程、取消令牌、文件接口、音源和解码器边界。每种架构运行 21 项播放用例，覆盖解析失败、空地址、打开失败、初始化失败、播放失败、定位失败、取消后旧回调、非播放用途、正常结束和集合误播放。

验证失败解码在主线程停止之前不会返回可触发跳曲的错误，停止后能退出，提示包含歌曲与原因；用户已经取消时，旧回调不能再次停止播放或显示提示。这些测试模拟 SDK 的线程契约，不能代替实际宿主验证。
