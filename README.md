# 适用于 foobar2000 的 LX 在线音乐组件

支持多音源切换、在线搜索与播放、歌词、音质回退、专辑和封面下载。

## 下载

- [foobar2000 v1.x · 32 位](https://github.com/lumiliya2009/foo_lxmusic/releases/download/v0.1.7/foo_lxmusic-0.1.7-fb1-x86.fb2k-component)
- [foobar2000 v2.x · 64 位](https://github.com/lumiliya2009/foo_lxmusic/releases/download/v0.1.7/foo_lxmusic-0.1.7-fb2-x64.fb2k-component)

## 使用

安装后重启，在“文件 → LX 在线音乐 → 管理音源”导入脚本，搜索时选择音源和站点。回车打开或播放，右键下载；菜单可检查更新。

需要 .NET Framework 4.8，音源需自行导入。
