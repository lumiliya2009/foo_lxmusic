# 适用于 foobar2000 的 LX 在线音乐组件

支持 QQ 音乐、酷狗、网易云搜索与播放，可获取歌词、切换音质、下载整张专辑和封面。

## 下载

- [foobar2000 v1.x · 32 位](https://github.com/lumiliya2009/foo_lxmusic/releases/download/v0.1.5/foo_lxmusic-0.1.5-fb1-x86.fb2k-component)
- [foobar2000 v2.x · 64 位](https://github.com/lumiliya2009/foo_lxmusic/releases/download/v0.1.5/foo_lxmusic-0.1.5-fb2-x64.fb2k-component)

## 使用

安装后重启，在“文件 → LX 在线音乐”导入音源并搜索。回车打开或播放，右键下载。

需要 .NET Framework 4.8，音源需自行导入。
