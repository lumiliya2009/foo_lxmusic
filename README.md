# 适用于 foobar2000 的 LX 在线音乐组件

支持多音源切换、在线搜索与播放、歌词、音质回退、专辑和封面下载。

## 下载

- [foobar2000 v1.x · 32 位](https://github.com/lumiliya2009/foo_lxmusic/releases/download/v0.1.18/foo_lxmusic-0.1.18-fb1-x86.fb2k-component)
- [foobar2000 v2.x · 64 位](https://github.com/lumiliya2009/foo_lxmusic/releases/download/v0.1.18/foo_lxmusic-0.1.18-fb2-x64.fb2k-component)

## 使用

安装后重启，在“文件 → LX 在线音乐 → 管理音源”导入脚本，搜索时选择音源和站点。回车打开或播放，退格返回上一层，右键下载或复制单首歌曲播放直链。直链有效期由音源决定。

“获取 QQ 号歌单”可输入 QQ 号或公开歌单分享链接，查看公开自建歌单、当前“我喜欢”和收藏的歌单；打开歌单后按原顺序进入播放列表。

音源管理会显示版本、作者、描述、支持站点与音质。在音源列表上右键可切换、编辑脚本、检查更新、复制来源地址或删除。

下载支持全部搜索页、1～16 个并发任务、失败跳过及完成后查重。查重只删除本次下载的重复副本，原有文件保留。文件名可用 `{序号}`、`{曲名}`、`{艺术家}`、`{专辑名}`、`{音质}` 组合，同名文件自动加后缀。

在“首选项 → 工具 → LX 在线音乐”（或菜单“设置…”）保存下载默认值，也可选择是否显示下载前的临时设置。

列表末尾可翻页、到尾页或输入页码跳转。搜索框保存最近 20 条记录，直接输入覆盖旧文字；多次搜索保留独立结果列表。

在“首选项 → 工具 → LX 在线音乐”中可关闭固定列表模式，让每次歌曲搜索创建新列表；开启后搜索会覆盖指定名称的播放列表，列表不存在时自动创建。

专辑、歌手、歌单和榜单在组件自己的浏览列表中显示，榜单只显示名称；打开后自动切回 foobar2000 歌曲列表，退格返回原来的浏览位置。直接搜索歌曲仍使用播放器列表。旧的榜单播放列表和歌曲搜索中的翻页项可选使用 [LX 显示列](PLAYLIST_DISPLAY.md)。

改返回键：在“首选项 → 快捷键”新增绑定，动作选“文件 → LX 在线音乐 → 返回上一层”。自定义后默认退格停用。

默认启动后自动检查组件更新，随后每小时检查，失败后稍后重试；可在设置中关闭。菜单“检查更新”也可手动检查，确认后优先从国内通道下载对应位数的安装包，并提供 GitHub 等备用通道；安装包会校验大小和 SHA256，替换失败恢复原文件。

需要 .NET Framework 4.8，音源需自行导入。
